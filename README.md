# Student Marks Calculator

## About the Project
This is my first Java project.
It calculates the total marks, percentage,
and grade of a student.

## Features
- Takes student name as input
- Accepts marks of 5 subjects
- Calculates total marks
- Calculates percentage
- Displays student grade

## Technologies Used
- Java
- Eclipse IDE

## Grade System
- 90% and above: Grade A
- 75% to 89%: Grade B
- 60% to 74%: Grade C
- Below 60%: Grade D
